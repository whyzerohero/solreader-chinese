# First Edition 与 v1.6.0

## 用户已确认的设备事实

Sol Reader First Edition，返回 `VERSION SEMVER,1.6.0;GIT,release/v1.6.0`。
运行 USB VID=303A、PID=4002，曾出现 MI_00=COM6、MI_02=COM7；
CONNECT 和 DEVICE_INFO 成功。
FREE_SPACE=37920768 字节只是文件系统剩余量，不能认定物理 Flash。
PROGRAM 未确认切换成功；OpenOCD 未发现 JTAG，之后 COM6 曾报 WinError 31。
仍可正常阅读，用户未擦除、改分区或刷写。本轮没有重测这些事实。
COM 编号是当次枚举结果，未来必须动态识别。

【离线验证】完整 Git 克隆包含历史、远端分支和标签：
release/v1.6.0 为 Tag，解析成提交
**7dcf0850daa5cec076c8d68e2f56cf413ff707aa**，未发现同名远端 Branch。
HEAD 的 git describe --tags --always --dirty 返回 release/v1.6.0。
[官方 Release](https://github.com/sindarin-inc/embedded-app/releases/tag/release/v1.6.0)
提供同 SHA 命名的 IDFv5.3.2 固件包和 epub-render 包。

【源码确认】[src/Version.cpp:10](https://github.com/sindarin-inc/embedded-app/blob/7dcf0850daa5cec076c8d68e2f56cf413ff707aa/src/Version.cpp#L10) 的 GitVersionString 从 esp_app_get_description()->version 取得版本，
SemanticVersionString/ExtractVersion 从 release/v 前缀提取语义版本；
[src/Version.hpp:5](https://github.com/sindarin-inc/embedded-app/blob/7dcf0850daa5cec076c8d68e2f56cf413ff707aa/src/Version.hpp#L5) 说明 git describe 生成机制。
[ESP-IDF project.cmake:693](https://github.com/espressif/esp-idf/blob/9d7f2d69f50d1288526d4f1027108e314e8c879f/tools/cmake/project.cmake#L693)
确认无覆盖版本配置时使用 git_describe，其他来源或配置可以覆盖 PROJECT_VER。
因此 GIT 字段实际是描述字符串，未提供完整实机 SHA 或二进制哈希。

【离线验证】官方包 SHA-256 与 GitHub API 公布值一致：
e89554cf80adf5fe650bfaa0b15cd12699170d80189a8a2783257042aa6a8818。

应用 3543696 字节，SHA-256=3f31f66f3e927b36d1b248766fd0f978ed3d076ff88a50e3587fcd65369871c5。
分区表与源 CSV 一致。完整公开包校验记录见 release_v1.6.0.json。
