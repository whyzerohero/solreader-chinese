# Roadmap

## Next engineering work

1. Diagnose the actual device stage behind the immediate sync failure, preserving certificate validation and error codes.
2. Investigate any repeated dictionary-lookup restart with raw logs and an ELF matching the installed firmware.
3. Continue Chinese glyph, punctuation, cache, and EPUB/TXT compatibility work based on real book samples.
4. Measure longer reading, sleep/wake, BLE, memory, power, and E Ink behavior. Keep C as the current preferred mode and E as the faster alternative.

## Future Chinese writing

A separate, dedicated **12-key one-handed Chinese T9 keyboard** is a planned input device for comfortable long-form writing with little reliance on touch input or a full-size keyboard. Planned software includes predictive syllable/phrase input, candidate selection, editing, note taking, and possible BLE keyboard integration. The existing five-button Sol Reader remote remains a reading control; it is not the proposed writing keyboard. No T9 or note-taking workflow is part of the ACE functional baseline.
