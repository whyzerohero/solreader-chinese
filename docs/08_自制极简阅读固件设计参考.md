# 自制极简阅读固件：上层产品设计参考

本项目面向 Sol Reader First Edition，利用可合法复用的官方硬件底层、驱动与工具，
开发自己的极简中文阅读固件。内部代号 wudada 指用户此前开发的自制极简阅读固件，
允许用于内部资料和算法适配记录，但不出现在公开 README 中。它不是 Sol Reader 硬件底层，
旧设备 GPIO、驱动、分区、电源、休眠及 firmware.bin 均不能直接套用。

## 产品参考与代码复用边界

用户此前自制极简阅读固件的阅读交互、分页、排版和功能设计，是本项目上层产品的重要参考。
可以先形成需求、交互规格、原创中文排版原型及合成测试，不需要等待旧工程导入。
本次已检查FIX6源码并运行主机/目标编译；不能宣称整个旧工程可直接编译或刷写到 Sol Reader。
不根据其他硬件的屏幕尺寸、芯片或固件版本推定其身份或兼容性。

若以后审计用户自制源码：先确认来源、版本、文件哈希和授权，隔离私人书籍、笔记与密钥；
再检查分页/排版算法、依赖、内存、屏幕和分区耦合，确定可合法复用的具体组件。
代码复用结论须有真实源码和离线测试证据，产品设计参考本身不表示代码移植可行。

平台适配保留 First Edition 的官方硬件研究、安全结论及锁定 SHA；
原厂五键遥控器只承担阅读控制，独立专用输入硬件的规格与通信方式另行设计。
没有生成可刷固件，不连接设备，不擦写；将来的设备操作需独立授权和可靠恢复证据。
