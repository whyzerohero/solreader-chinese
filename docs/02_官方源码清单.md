## 构建依赖与复用范围

- embedded-app：ESP-IDF v5.3.2、ESP32-S3、CMake/Make/Python；
  八个直接 Git 子模块的 URL/SHA 全部记录在 lock，未递归初始化。注册组件 esp_tinyusb=1.5.0；
  P4 专用的 ili9881c、esp_wifi_remote、esp_hosted 不应进入 First Edition。
  复用显示/电源/遥控器/存储/USB/阅读，须先解决授权。
- tiny-epub：renderer、epubfile；pugixml/miniz、cpp-misc 的 unzipper/PSRAM/string 等，
  components/mbedtls 有固定 gitlink；主机测试需要 CMake、PNG 等。
  复用流式 EPUB、既有分页模型，主机无屏幕依赖，但非 v1.6.0 即插即用版本。
- tiny-font：IBMF 1bpp + FreeType TTF、freetype 固定 gitlink；
  idflog Git 依赖没有 ref，主机 CMake FetchContent 也会取 cpp-misc main。
  依赖图仍未完整锁定，不能称为可复现固件。
- desktop-app：requirements.txt 固定 PySide6_Essentials=6.7.2、pyserial=3.5、
  EbookLib=0.18、esptool=4.7.0 等，setuptools 未固定；没有 Git 子模块。
  README 自述为原型并提到 embedded-app 1.0.7 兼容性；不能据此宣称 v1.6.0 已验证，
  更不能视为完成的 Windows 一键刷机工具。
- cpp-misc：bmpimage/defer/idflog/spiram-cpp/stringutil/unzipper/imagetest；
  无 Git 子模块；PNG 为图像测试依赖。用于未来组件边界参考。
- astubs：Update/MD5、ESP-IDF OTA/分区 API；无需重写官方更新库，
  但调用方的恢复流程必须另行核验。
