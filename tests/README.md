# 离线检查与后续测试矩阵

当前检查：
- 来源锁定、必需目录文档、隐私忽略规则、固定源码 HEAD/子模块：verify_project.py。
- 原创接口可由 C++17 主机编译器解析：contract_compile.cpp，仅语法及静态类型边界验证；确认组合接口拒绝原厂阅读事件，不证明运行时输入法已实现。
- 官方附带 IBMF/TTF Unicode 字符覆盖：audit_fonts.py。

后续中文布局测试必须使用原创合成文本，不提交用户书籍：
| 范围 | 用例与验收 |
| --- | --- |
| UTF-8 | ASCII/汉字/扩展字、过长编码、代理项、截断、不合法字节；正确拒绝或替换，游标不落在续字节 |
| 中文断行 | 无空格长段落、全角空格、中英数字混排；前后翻页、跳转不丢字不重字 |
| 禁则 | 行首逗号句号闭括号、行尾开括号、成对省略号/破折号、极窄行 |
| 字体 | 常用汉字、标点、ASCII、未知字回退；资源许可与覆盖清单，缓存有上限 |
| 进度 | 字号切换、内容变更、TXT 转码、EPUB spine；原厂位置兼容与稳定恢复 |
| 遥控器 | 已确认通知录制的离线回放，阅读路由与阅读事件一致，不流入输入法；未确认按键不造事件 |
| 专用输入硬件接口 | 独立语义事件，禁止原厂遥控事件进入组合接口；硬件规格和通信待设计 |
| 笔记 | UTF-8 游标、删除、撤回、保存失败、原子文件中断、旧 revision 冲突 |
| 资源 | 大文本流式处理、最长段落、峰值内存和每页耗时，不能用源码缓冲上限冒充实测 |
| 恢复 | 假分区/错误返回值、损坏固件、断电时序；任何真实写入单独授权 |

本轮未运行上游 Catch2、模拟器或 ESP-IDF，也没有实机测试。
